# Project naming recommendation

## Exact recommendation

**GitHub slug:** `obscura-metamaterial-observability-lab`

**Display title:** **OBSCURA: Programmable Metamaterial Dual-Observability Lab**

**Acronym:** **O**bservability **B**enchmark for **S**imulated **C**loaking **U**nder **R**educed-order **A**daptation

## Why this name works

1. **OBSCURA is memorable.** It evokes controlled hiding without asserting that invisibility was achieved.
2. **Metamaterial identifies the research domain.** The code includes an ideal active effective-medium benchmark plus named graphene, GO/rGO, hBN, and ITO comparator models.
3. **Observability is the scientifically correct centerpiece.** The implemented gates are QFI, capture, shadow, detector loss, and optional wave/channel metrics.
4. **Lab signals an experimental software sandbox.** It does not imply a fabricated device.
5. **The acronym embeds the disclaimer.** “Simulated” and “reduced-order” travel with the brand rather than hiding in fine print.

## Recommended one-line claim

> Simultaneous below-threshold quantum and classical observability in a declared reduced-order programmable-metamaterial benchmark.

## Recommended GitHub description

> Reduced-order programmable-metamaterial control lab for simultaneous suppression of classical detector observability and per-probe QFI under explicit spectral, wave, energy, and lifecycle thresholds.

## Names I would not use as the primary repository title

### `simulated-programmable-metamaterial-invisibility`

“Simulated” helps, but “invisibility” still sounds like the primary established outcome rather than a thresholded model result.

### `quantum-invisibility-cloak`

This would overstate both the quantum model and the physical conclusion. The quantum layer is a reduced 3-state channel and a sampled finite-channel audit, not a universal quantum-cloaking proof.

### `broadband-omnidirectional-invisibility`

The default source is sampled across a declared visible interval and a 96-direction quadrature. That is not a continuous wavelength-angle proof or experimental broadband omnidirectional validation.

## Precise alternatives

- `programmable-metamaterial-observability-lab`
- `dual-observability-cloak-control`
- `reduced-order-metamaterial-cloaking-benchmark`
- `qfi-classical-observability-control-lab`

The first alternative is the most literal. OBSCURA is the strongest blend of rigor and identity.
